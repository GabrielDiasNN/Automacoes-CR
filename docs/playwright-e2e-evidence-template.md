# Template de Evidência E2E Final (Playwright)

Preencha este bloco ao final de cada entrega que exija validação E2E Playwright.

## Evidência E2E Final
- Data/Hora (BRT): `<YYYY-MM-DD HH:mm:ss>`
- URL validada: `http://127.0.0.1:8000/dashboard/`
- Ordem de execução: `Governança -> Testes de contrato/backend -> Playwright E2E (último)`
- Módulos navegados:
  - `Comando`
  - `Automações`
  - `Execuções`
  - `Observabilidade`
  - `Sistema`
  - `Configuração`
- Ações críticas validadas:
  - `Listagem/refresh de execuções`
  - `Aplicação de filtro em execuções`
  - `Abertura de logs`
  - `<outras ações relevantes da mudança>`
- Console do navegador:
  - `Erros: <0|N>`
  - `Warnings: <0|N>`
  - `Resumo: <sem erros|descrever>`
- Resultado final:
  - `Aprovado` ou `Reprovado`
- Pendências (se houver):
  - `<bloqueios técnicos para aceite final>`
